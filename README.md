# 오늘 공부

UI/UX 프로그래밍 중간 프로젝트입니다. HTML, CSS, JavaScript로 간단한 공부 계획 페이지를 만들었습니다.

## 서비스와 사용자
- 사용자: 여러 과목을 공부하면서 오늘 할 일을 정리하려는 학생
- 목적: 과목, 공부할 내용, 시간을 정하고 저장한 계획을 나중에 다시 확인하기
- 주요 행동: 계획 입력 → 내용 확인 → 저장 → 저장한 계획 다시 열기

## 기본 흐름과 추가한 기능
7주차 원본 프로젝트가 없어 이번에 입력·확인·수정 흐름부터 새로 작성했습니다. 과거에 작성한 7주차 결과물을 수정한 작업은 아닙니다. 기본 버전과 저장 기능 추가 버전을 커밋으로 나눠 차이를 남겼습니다.

기본 흐름의 끝에 계획을 목록으로 저장하고 다시 여는 경로를 추가했습니다. 필요 없는 계획은 확인 후 삭제할 수 있습니다.

## 새 기능의 동작
1. 확인 화면에서 '이 계획 저장하기'를 누릅니다.
2. 같은 과목·내용·시간의 계획이 이미 있는지, 저장 개수가 10개 미만인지 검사합니다.
3. 조건을 만족하면 목록에 추가하고 저장 완료 안내를 보여 줍니다. 이후 목록에서 '다시 열기'를 눌러 내용을 확인합니다.
4. 중복이면 기존 목록에서 다시 열도록 안내합니다. 10개가 차면 필요 없는 계획을 삭제하도록 안내합니다.
5. '삭제'를 누르면 한 번 더 확인합니다. '취소'를 누르면 계획이 그대로 남고, '삭제하기'를 누르면 목록에서 빠집니다. 마지막 계획을 삭제하면 빈 목록 안내가 나옵니다.

과목이나 공부할 내용을 비워 두면 해당 칸을 입력하라는 안내가 나옵니다. 시간을 고르지 않아도 안내합니다. '내용 수정하기'로 돌아가면 입력값을 유지하고, '새 계획 만들기'는 작성 중인 값만 초기화합니다. 저장한 목록은 지우지 않습니다.

## 파일 구성
- index.html: 입력 폼, 확인 화면, 저장 목록
- style.css: 기본 배치, 안내 상태, 모바일 화면
- script.js: 입력 검사, 버튼 이벤트, 목록 갱신, localStorage 저장

## 실행과 배포
index.html을 브라우저에서 열면 됩니다. 별도 설치나 서버는 필요 없습니다.

## 한계
계획은 같은 브라우저에만 저장됩니다. 다른 기기와 동기화되지 않고, 브라우저 데이터를 지우면 사라집니다. 공용 컴퓨터에서는 사용 후 계획을 삭제해야 합니다. 실제 알림이나 로그인 기능은 없습니다.
